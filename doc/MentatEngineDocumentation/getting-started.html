Getting Started

This page mirrors the current repository layout and Windows workflow included in the uploaded engine package.

Requirements

ToolExpected version / note
Python3.11
Conan1.66.0
CMake3.27.6
GeneratorVisual Studio solution via tools/genproj.bat

1. Install Conan on Windows

python --version
pip install "conan==1.66.0"
cmake --version
The current README explicitly warns that newer Python versions may cause issues with Conan 1.66.0.

2. Generate the Visual Studio solution

cd C:\path\to\MentatEngine
tools\genproj.bat

The generated solution is expected at build/MentatEngine.sln.

3. Documentation workflow

This package includes an offline website plus a synced source snapshot under MentatEngine/.

MentatEngineDocumentation/
├─ index.html
├─ editor-panels.html
├─ getting-started.html
├─ how-tos.html
├─ showcase.html
├─ Doxyfile
└─ MentatEngine/
   ├─ include/
   ├─ src/
   └─ examples/

If you have Doxygen installed on Windows, regenerate API docs from this folder:

cd C:\path\to\MentatEngineDocumentation
doxygen Doxyfile

4. Current renderer landscape

  • Phong is the default interactive path used in multiple demos and editor iteration.
  • Shadow Map is selectable and used for shadow validation work.
  • Deferred has a dedicated demo and editor menu entry.
  • PBR exists in the API enum and renderer code, but the editor menu currently exposes only Phong, Shadow Map and Deferred.
