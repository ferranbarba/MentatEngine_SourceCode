How To's

Recipes updated to the current engine snapshot and example code.

1. Create the core and select a renderer

std::optional<ME::Core> maybe_core =
    ME::Core::create(1280, 720, "My Scene", ME::APIType::OpenGL);
if (!maybe_core) return -1;

ME::Core core = std::move(maybe_core.value());
core.InitRenderer(true);
core.GetGraphicAPI()->StartRenderers();
core.GetGraphicAPI()->SetRenderType(ME::RenderType::Phong);

2. Enable async helpers used by the editor

ME::MeshLoader::js_ref_ = core.GetJobSystemRef();
ME::TextureLoader::js_ref_ = core.GetJobSystemRef();
ME::ImGuiManager::renderer_ = core.GetGraphicAPI();
The latest scene-based demos wire the job system into mesh and texture loading before opening the editor flow.

3. Bind the editor fly camera and gizmo cycling

ME::Input input(core.window());
input.SetRuntimeModeProvider(&ME::ImGuiManager::IsRuntimeInputMode);
input.BindEditorKey(ME::Input::Action::FlyEnable,   ME::Input::InputKey::MB_Right);
input.BindEditorKey(ME::Input::Action::FlyForward,  ME::Input::InputKey::W);
input.BindEditorKey(ME::Input::Action::FlyBackward, ME::Input::InputKey::S);
input.BindEditorKey(ME::Input::Action::FlyLeft,     ME::Input::InputKey::A);
input.BindEditorKey(ME::Input::Action::FlyRight,    ME::Input::InputKey::D);
input.BindEditorKey(ME::Input::Action::FlyDown,     ME::Input::InputKey::E);
input.BindEditorKey(ME::Input::Action::FlyUp,       ME::Input::InputKey::Q);
input.BindEditorKey(ME::Input::Action::CycleGizmoMode, ME::Input::InputKey::SPACEBAR);
ME::ImGuiManager::SetInput(&input);

4. Load the title scene / scene picker flow

ME::Core::InScenesPage = true;
ME::XMLManager::FileToScene("DefaultScene", true);
ME::ImGuiManager::RegisterScenesWindow();

The latest editor-oriented demos start in the title scene and then open either a new scene or an existing one from deps/resources/scenes.

5. Create a renderable entity

ME::LoadedDrawable mesh =
    ME::MeshLoader::LoadObjPositionsFlat("../../deps/resources/horse.obj");

ME::Entity model;
model.AddComponent<ME::RenderizableComponent>(
    mesh.vertices.data(), mesh.vertices.size(),
    mesh.indexes.data(),  mesh.indexes.size(),
    Vec3{1.0f, 0.0f, 0.0f},
    "../../deps/resources/horse.obj"
);
model.AddComponent<ME::TransformComponent>();

6. Add a light that can cast shadows

ME::Entity lightEntity;
lightEntity.AddComponent<ME::TransformComponent>();
auto& light = lightEntity.AddComponent<ME::LightComponent>();
light.SetType(ME::LightComponent::Type::DIRECTIONAL);
light.SetCastsShadows(true);
light.SetShadowNear(0.1f);
light.SetShadowFar(25.0f);
The Details panel now exposes light enable state, type, diffuse/specular colors, spec intensity and shadow near/far tuning.

7. Drop textures or scripts from the Explorer

The current editor supports drag & drop payloads from the Explorer window into component fields. The most useful flows are:

  • Drop a texture file onto a render component texture target.
  • Drop a script file onto the Script component path target.
  • Drop files from the Explorer rather than hardcoding every assignment.

8. Switch renderers from the editor

The current top menu exposes these runtime renderer options:

  • Phong
  • Shadow Map
  • Deferred
Although RenderType::PBR exists in the engine API, it is not currently listed in the ImGui Renderers menu.
