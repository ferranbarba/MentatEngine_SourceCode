1. The engine freezes if Visual Studio console gets focus

Symptom: right after launching the engine, if you click on the Visual Studio console window, the engine appears to freeze.

Why it happens: the running application loses normal input/update focus when the console window becomes the active window. From the user perspective, it looks like the engine has hung.

Important: when you start the engine, do not click on the Visual Studio console. Keep focus on the engine window.

How to avoid it

  • Launch the project and click directly on the engine/editor window, not on the console.
  • If you need to inspect logs, avoid leaving the console as the active window while testing real-time interaction.
  • For presentations or captures, start the demo and interact only with the engine window.
Suggested note for users: this is currently a known issue in the development build, not a scene-specific bug.
