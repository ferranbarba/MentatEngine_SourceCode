What changed versus the old web

  • The docs now mention DEMO_09_deferred and DEMO_10_PBR.
  • The editor flow now starts from a title scene in the scene-based demos.
  • Deferred rendering is no longer absent from the website.
  • PBR exists in the engine API and demo set, even if the editor menu is not yet exposing it directly.

Recommended reading order

  1. Read DEMO_01 to DEMO_04 for the basic engine and component workflow.
  2. Use DEMO_05 and DEMO_07 to understand async tasks and scripting.
  3. Use DEMO_08 and DEMO_09 to study the current editor-centric workflow.
  4. Review DEMO_10 as the place where PBR integration is being staged.
