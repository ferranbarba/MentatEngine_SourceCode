Editor Panels

This page was refreshed from the latest ImGuiManager implementation and now matches the current menu bar, windows and inspector behavior.

Main Menu Bar

MenuCurrent entries
SceneSave Scene, Exit to Menu
WindowsScene, Performance, Details, Outliner, Fly cam config, Explorer, Editor Input Bindings, Gizmo Controls, Budget System
EntityCube, Sphere, Pyramid, Horse, Square, Triangle, Ambient, Directional, Spot, Point
RenderersPhong, Shadow Map, Deferred
The center of the menu bar also hosts Play, Pause and Stop. Play serializes the current scene, Pause toggles runtime pause, and Stop reloads the saved editor snapshot.

Title Scene

The title flow is no longer just a placeholder. It contains:

  • NEW SCENE with scene name validation.
  • LOAD SCENE to open existing scene files.
  • Scene name safety checks against invalid file-system characters.

Scene Viewport

The viewport window displays the current renderer output texture, updates scene size on resize and deliberately releases mouse/keyboard capture while hovered so editor navigation remains responsive.

Entity Hierarchy

  • Tree-based outliner of root entities and children.
  • Drag one entity onto another to parent it.
  • Drop an entity on the root target to unparent it.
  • Render visibility can be toggled and propagated to children.

Details Inspector

The inspector title reflects the selected entity tag and supports live component editing.

SectionCurrent editing features
TagRename entity, delete entity
TransformPosition, rotation, scale, remove Transform component
RenderVisibility, color active toggle, texture target, mesh assignment via drag & drop, remove component
LightEnabled, type, cast shadows, shadow near/far, diffuse/specular colors, spec intensity, position source from Transform when available
CameraFOV, near, far, active flag
ScriptScript path / drag & drop assignment, remove component
The inspector also supports adding missing components dynamically: Transform, Renderizable, Light, Camera and Script.

Gizmo Controls

The current gizmo system is more complete than the old docs suggested:

  • Modes: Translate, Rotate, Scale
  • Space: World or Local
  • Per-mode sensitivity sliders
  • SPACEBAR cycles gizmo mode when the editor is not playing

Explorer

The Explorer scans resources with a grid/icon view and supports drag & drop payloads named EXPLORER_RESOURCE. It is intended for mesh, texture and script assignment from within the editor.

Editor Input Bindings

This panel prints the currently registered editor actions and all keys attached to each action using a two-column ImGui table.

Performance + Memory Budget

  • Performance shows frame time and FPS.
  • Memory Budget tracks GPU texture and buffer memory against current budgets.
  • Bars turn red when budgets are exceeded.
